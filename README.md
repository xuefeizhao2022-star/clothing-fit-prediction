## 网站入口
- [打开网站首页文件](./index.html)
- 若启用 GitHub Pages，网站可作为公开访问的作品集。

## 使用
直接打开 `index.html` 可预览。网站支持项目搜索、岗位筛选、项目对比、中文简历描述和面试提纲生成。项目详情可在本浏览器编辑并导出 JSON；**本地修改不会自动同步到 GitHub**。

## 事实与隐私声明
- 课程项目不等于企业委托项目。
- 小组项目只描述已知的个人贡献。
- 山火项目是方案设计，非部署系统。
- SQL教学样例是模拟数据，非真实店铺交易。
- Lolita Market Watch仍在开发测试中。
- 部分结果及个人经历的数字待与原始材料核实。
- 公开前应检查 Notebook、数据和截图是否含账号凭据、Cookie或敏感信息。

## GitHub Pages 发布
在仓库 **Settings → Pages → Build and deployment** 中，选择 **Deploy from a branch**，分支 **main**、目录 **/(root)**，保存并等待 GitHub 提供网站地址。此步骤需仓库所有者在 GitHub 页面操作。
